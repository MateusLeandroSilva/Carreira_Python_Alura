## 📋 Sobre o Projeto

Repositório destinado ao armazenamento de projetos, exercícios e materiais de estudo desenvolvidos durante a **Formação em Desenvolvimento Backend com Python** pela Alura. Este material documenta minha jornada de aprendizado e evolução na linguagem Python aplicada ao desenvolvimento backend.

## 🎯 Objetivos da Formação

- Dominar os fundamentos da linguagem Python
- Desenvolver aplicações backend robustas e escaláveis
- Compreender conceitos de programação orientada a objetos
- Trabalhar com bancos de dados e APIs
- Aplicar boas práticas de desenvolvimento

## 🚀 Como Executar os Projetos

### Pré-requisitos

- Python 3.x instalado
- Git instalado

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2. Navegue até o diretório do projeto:
```bash
cd seu-repositorio
```

3. Execute os arquivos Python:
```bash
python Apostiça/app.py
```

ou

```bash
python Exercícios/Exercício2.py
```
